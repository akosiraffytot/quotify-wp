Quotify shortcode reference

All shortcodes, their attributes, allowed values and what each does. Copy these into any page or post.

Bricks Builder dynamic data

With Bricks Builder active, Quotify adds two dynamic data tags under the Quotify group in the Dynamic Data dropdown. They render the current logged-in visitor's saved scan: empty (so you can hide elements with Bricks conditions) when the visitor is logged out or has never scanned.

  • {quotify_page_count} — the visitor's saved page count, formatted with thousands separators.
  • {quotify_price} — the price for that count from your Tools > Quotify tiers (or the contact-us fallback when no tier matches).

Example in a text element: “Your site has {quotify_page_count} pages — {quotify_price}.”

The estimate form

[quotify]

Renders the full website estimator: a URL field, the Estimate button, a spinner and inline result fields. Results fill in live over AJAX — no page reload.

AttributeDefaultAllowedWhat it does
buttonEstimatestringText on the submit button.
quote_labelGet a QuotestringText on the checkout link/button shown after the estimate.
show_pages10 / 1Show the page count inline after the estimate.
show_price10 / 1Show the price inline after the estimate.
show_quote10 / 1Show the quote/checkout link inline after the estimate.
modeallall, userall — visitors type any website. user — prefill (read-only) from the logged-in visitor's profile website URL; shows a prompt when none is set.
instant_checkout(off)yes, 1, true, onTurn the quote button into FluentCart's instant modal checkout. Requires FluentCart active and a Variation ID set on the matched pricing tier; the tier's Checkout URL is ignored while on. Leave off / omit to use checkout URLs.
force_load_assets(off)yes, 1, true, onEmbed the frontend CSS/JS directly with the form for placements that render after the normal asset queue — builder popups, step wizards, late-printed content. Off: assets load once automatically when a Quotify shortcode renders on the page.

Example:

[quotify button="Get my price" quote_label="Buy now" mode="user"]

Estimate button says “Get my price”, checkout label “Buy now”, and the field is prefilled with the logged-in visitor's profile URL.

Place results anywhere

These fill with the values from the last estimate run on the page. If the inline fields are hidden on [quotify] (show_pages="0" etc.), drop these in separate spots to show the values there instead.

  • [quotify_count] — the counted page number
  • [quotify_price] — the matched price
  • [quotify_quote] — the “Get a Quote” link/button
AttributeDefaultAllowedWhat it does
placeholder(empty)stringText shown before the first estimate on the page.
labelGet a QuotestringOnly on [quotify_quote]. Text of the quote link/button.

Example:

[quotify_count placeholder="--"] [quotify_quote label="Buy now"]
Tip: when instant_checkout="yes" is on [quotify], a [quotify_quote] on the same page also renders the FluentCart modal button.

Logged-in users' saved scan

When a logged-in visitor runs a successful estimate, Quotify saves the page count, scan date/time and scanned URL to their profile (latest scan only). These shortcodes render the saved values server-side — no form or AJAX needed. They output an empty string (or the placeholder) when the visitor is logged out or has never scanned.

  • [quotify_saved_count] — the visitor's last saved page count
  • [quotify_saved_scanned] — the date + time of the last scan (site formats)
  • [quotify_saved_url] — the last scanned website URL
AttributeDefaultAllowedWhat it does
placeholder(empty)stringFallback text when no saved scan is available.

Example:

Your latest scan: [quotify_saved_count placeholder="—"] pages, checked [quotify_saved_scanned placeholder="never"].

Custom-quote / standalone checkout button

On a custom-quote tier (Tools > Quotify), no fixed price is shown — visitors get a per-tier button instead. Add the button anywhere with the standalone shortcode:

[quotify_fluentcart_checkout]

Server-rendered for the current logged-in user's saved scan (no form, no AJAX): it matches the saved page count to a tier and renders the right button — the FluentCart instant-modal checkout when the tier has a Variation ID, or a link to the tier's Checkout URL when not. Custom-quote Checkout URLs are used verbatim, so mailto:, tel: and relative links work, and the {site} / {page_count} tokens are substituted there too ({total_price} stays literal on custom-quote tiers).

  • label — button text when the tier has no per-tier label set (default: Get a Quote).
  • force_load_assets — yes/1/true/on to embed the frontend assets inline (for builder popups / late-printed placements).

Outputs nothing when the visitor is logged out or has never scanned.
